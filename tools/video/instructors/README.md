# Driving instructors "how it works" video (video/instructors.mp4)

Made 22 Nov 2026. 2 min 18, 1280x720, same voice and method as the recovery video: see `../recovery/README.md`
(`voice.py` and `check-voice.py` there are used unchanged, pointed at this folder).

- `script.json`: what is said and the captions. `slides.html` + `render.js`: the slides. `compose.py`: the finished video.
- Opening picture: `img/driving-lessons.webp`. Screen pictures (c1 to c3, p1 to p5) were taken from the preview site
  with the test driving school, with the test names swapped for sample names. They are not kept here.
